# DG-AI-Bot
A discord bot made for DG Develops but is available for everyone. What it does:

* **Anti Bot Verification**
* **Announcements**
* **Summarizes messages using AI**
* **Can answer any question including questions about DG Develops**

## Commands:

* `/summary` [message url: XXXXLink from discordXXXX]
* `/verify`
* `/ask`
* `/announce`

## How does `/verify` work ?
The `/verify` command sends a DM to the user which which there is a embed card and a link: "Click here to verify", when the user clicks the link he/she is redirected to the verification portal where Cloudflare Turnstile checks that if they are humans or bots.

*Note: `/ask` was built for asking doubts about DG Develops however, it can also be used to ask the AI models other things that you wanna know !!!*
